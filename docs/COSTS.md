# 成本设计

核实日期：2026-09-20。币种 USD；未含税、域名和已有账号其他项目消耗。以下估算不是费用上限或平台报价承诺，实际以账户账单为准。

## 为什么媒体不放 GitHub

GitHub 对普通 Git 文件有 50MiB 警告、100MiB 阻止推送的限制；仓库还会保留版本历史。对持续增加的 PNG/视频，Git LFS 又引入单独的带宽/存储管理。这里直接约定：**代码和文本进 Git，生产媒体只进 R2**。[S1]

GitHub 是代码/内容版本库，不作为本站图片 CDN。提交 PR 的媒体临时附件也不当成永久存储。仓库目标尽量保持轻量，构建不拉取整个 R2。

## 选用的计费路径

| 项目 | 初期预算方式 | 说明 |
|---|---|---|
| GitHub 公共仓库 | 不因本设计新增专门存储订阅 | 只存文本与代码，不上 LFS |
| GitHub Actions | 公共仓库标准 runner 免费运行时 | 不用付费 larger runner；避免大型 artifacts/cache [S2] |
| Workers Static Assets | 静态请求免费且不限次数 | 只有匹配静态资产的路径；Worker 调用另计 [S3] |
| 管理 Worker | 优先免费档 | 100,000 次/天、每次 10ms CPU；要测真实 CPU [S4] |
| R2 Standard | 免费额度内可为 $0 | 按账户汇总存储与操作数 [S5] |
| Access | 按单维护者评估免费方案 | 官网仍列免费计划；控制台核对当期权益，不把大团队 seat 预算带进来 [S8] |
| 域名 | 另计或复用已有域名子域 | 不给未核实的固定域名价格 |

生产默认用 GitHub Actions 构建部署，不重复启用 Workers Builds 自动构建，避免一次 commit 触发两条部署。如果改用 Workers Builds，其免费档目前为 3,000 build minutes/月，需单独观察；不与本方案混算。[S6]

R2 需要先完成账户的 R2 subscription 开通流程；有免费额度不代表完全不用配置计费。[S7]

## R2 单价与免费额度

Standard：存储 $0.015/GB-month，Class A $4.50/百万次，Class B $0.36/百万次；直接从 R2 输出的公网 egress 不收费。每月包含 10GB-month、100 万 A、1,000 万 B；只适用于 Standard。存储按日峰值的月度平均形成 GB-month，并按计费单位向上取整。[S5]

**两只 R2 桶不等于两份免费额度。** 公开媒体、暂存文件、缩略图、旧版本和同账号其他项目要一起算。备份如果另存一份在 R2，也占存储。

## 稳态存储情景

假定额度尚未被别的项目消耗，整月保持相应 GB-month，操作数在免费额度内：

| 实际存储 | 计费存储 | 每月 R2 存储费用 |
|---|---|---|
| 5 GB | 0 GB | $0.00 |
| 10 GB | 0 GB | $0.00 |
| 50 GB | 40 GB | $0.60 |
| 100 GB | 90 GB | $1.35 |
| 500 GB | 490 GB | $7.35 |
| 1,000 GB | 990 GB | $14.85 |

这是依据 S5 的算术示例，不含额外操作费用。非整数使用量需要取整；不是对账工具。

一个容量假设：1,000 张结果图，平均原图 4MB + preview 0.5MB + thumbnail 0.15MB，约 4.65GB；100 段视频，平均 30MB + poster 0.15MB，约 3.015GB；合计约 7.665GB。此处 MB/GB 使用十进制，体积均为假设，真实文件大或视频多时增长很快。

## 读取和写入仍需关注

R2 的“零 egress”不等于“无限访问永不收费”。CDN 未命中的 GET/HEAD 等属于读操作，上传/复制/列举等产生写类操作。每个图片做原图+预览+缩略图并先暂存再复制，会有多次操作；个人写入量通常小，但不能把操作数忽略为固定零。

超额操作按百万次单位向上取整。例如 B 从 1,000 万增加到 1,000 万零一次，工具按额外一个百万次单位估算 $0.36；A 类同理。避免在每个访客请求都执行 R2 ListObjects 或 GitHub API。[S5]

## 控费默认值

列表仅加载 thumbnail；视频不自动播放/预加载原片；详情使用 preview，主动下载才取 original。派生图在浏览器处理，V1 不启用 Cloudflare Images/Stream 的额外计费链。

私有 staging 7 天清理；公开媒体保持不可变且不自动删除。每月查看 R2 存储和 A/B 请求、Worker CPU/请求；设置预算提醒（提醒本身不保证硬性止付）。若实际管理请求超过 Free CPU 约束，再考虑 Workers Paid 的 $5/月基础计划，不能只因流量不大就忽略 CPU 限制。[S4]

## 可执行估算器

```bash
npm run cost -- --gb 100 --a 10000 --b 1000000
# 同账户免费存储已被别的项目用完
npm run cost -- --gb 100 --free-gb 0 --a 10000 --b 1000000
```

输入 GB-month 与月操作数。工具只估 R2 Standard，输出逐项计费单位、费用和假设；不包含 Workers、Access、域名、税和其他产品。
