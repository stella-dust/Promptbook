# 实施顺序

不按团队/服务拆一堆并行任务，按可看见、可验证的用户流程递进。

## M0 · 工程与合同

建立 Astro 静态工程、TypeScript、React editor island、Worker 独立入口；锁定依赖与 Node 版本，提交 lockfile。保留设计包检查脚本，整理 npm scripts。

将 JSON Schema 接入构建和表单/API 等价校验，创建内容读取、分类读取、稳定 id 生成。模板/fixture 与 production content 隔离；空生产库可正常构建。

完成标准：`npm ci`、静态构建、类型检查、schema 测试通过；无 Secrets 也能运行本地演示；prototype 不进入生产构建。

## M1 · 公开页面与视觉确认

实现首页卡片、分类/搜索/类型/模型/排序、详情媒体展示、Prompt 复制、返回保留筛选和位置、贡献页、空态与 404。

用明确标记的测试图片、九宫格、超长图、短视频和长 Prompt 验证。公开页不发起 GitHub/鉴权/模型 API 请求。

完成标准：功能测试通过，提供 DESIGN 指定尺寸截图；待本人确认再继续 M2。不要用“以后再改 UI”略过这一阶段。

## M2 · 真实本地录入

实现标题/Prompt/结果上传/模型/分类五项主流程；高级字段折叠；图片剪贴板、拖放；封面选择；本地读取媒体元信息；预览和 JSON 导出。

使用 IndexedDB 保存草稿和 Blob；测试刷新恢复、容量不足、未保存离页、删除草稿。实现兼容视频验证/手动封面。

完成标准：不用云服务也能完成真实文件录入与恢复；不把原型 localStorage 文字存档当作全部草稿能力。

## M3 · 维护者授权与 R2

配置 Access 路径；Worker 二次 JWT 校验、Origin 检查、body 限额。实现签名直传、私有 staging、验证/finalize、幂等复制、原图/缩略图分离，全部按 API 合同。

完成标准：未授权/伪造/过期 JWT 和跨域写入均失败；真实图片和短视频在 staging → media 正常；中断重试不重复上传全部文件。未设置凭证时安全拒绝，不能进入 mock success。

## M4 · GitHub 内容发布与贡献

实现最新文件读取 + SHA，提交新记录与编辑；归档；revision 状态机；CI 校验和 main 自动部署；build-info 轮询；submission 模板导入。

完成标准：从真实文件新建到公开页面可见完整跑通；409 不覆盖；GitHub 超时后检查 revision；构建失败保留旧站并说明；贡献整理后入库且署名保留。

## M5 · 上线验收与运维

执行 ACCEPTANCE 所有上线必测项；审查 payload/日志无敏感信息；测试自有媒体域名缓存和视频 Range；检查首次费用、R2 订阅、域名、CI Secrets 范围；完成元数据 + R2 备份/恢复演练。

完成标准：提供真实域名、commit/revision 对应证据、桌面和手机截图、测试报告与运维指南。得到本人明确发布授权后才部署正式域名。不要以 localhost 截图声称正式上线。

## 延后清单

批量导入、自动跨设备私有草稿、分片上传、视频转码、图像相似搜索、多模型结果对比、自动元信息抽取、公开投稿后台都不阻塞 V1；有真实需求再按独立改动评估。
