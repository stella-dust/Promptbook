# 验收清单

每项记录实际结果。`[ ]` 不可在没有证据时批量改成 `[x]`。视觉原型通过不等于正式应用通过。

## A. 用户主流程

- [ ] 空库有新建入口，无假的模型作品、假的记录数。
- [ ] 新建真实图片：粘贴 Prompt → 拖入 PNG → 类别/模型 → 发布 → 公开首页/详情可见。
- [ ] 原始 Prompt 含中文、emoji、换行、反引号、JSON、`<script>` 字样时无改写；复制逐字符一致，HTML 不执行。
- [ ] 一条多输出可切换，封面正确；所有输出属于同种 kind，跨种类友好拒绝。
- [ ] 视频首页不自动播放、不下载原视频；详情可播放/拖动/暂停/音量/全屏。
- [ ] 平台与模型显示名、模型 ID 明确分开；未知 ID/seed 不填虚假值。
- [ ] 搜索/类型/类别/模型交集准确，URL 可分享，返回恢复筛选/滚动。
- [ ] 新建、编辑、复制为新记录、归档的语义不同；修改标题不改变 id/永久链接。
- [ ] 投稿导入保留 author/source/license；submission 本身不进入公开列表。

## B. 草稿和故障

- [ ] 真实草稿正文与 Blob 刷新后恢复；配额不足不丢文字。
- [ ] 未保存离页有提示；本地草稿不出现在静态产物/GitHub/公开 R2。
- [ ] 中断单个上传后只重试失败对象；已完成的 final 引用可复用。
- [ ] GitHub 409 不覆盖；GitHub 写入超时先比较远端 revision 再重试。
- [ ] commit 成功但构建未完成时显示“等待网站更新”；revision 上线后才显示“已上线”。
- [ ] 构建失败仍可访问旧版站点，管理端保留记录与错误/commit 入口。
- [ ] 两次很近的提交/并发 finalize 不产生丢更新或重复对象/错误删除。
- [ ] staging 清理不删已发布资源；git revert 后旧媒体仍能加载。

## C. 安全（上线阻塞项）

- [ ] `/admin`、`/admin/`、子路径、`/api/admin/*` 均正确保护。
- [ ] 缺失 JWT、伪造 JWT、错误 issuer/aud/email、过期 token 全部拒绝。
- [ ] `workers.dev` / preview URL 不能绕过管理授权；生产关闭或同等保护。
- [ ] Access 配置丢失时 fail closed；无前端共享密码/密钥。
- [ ] 跨站 Origin、非 JSON 写入、超限 body、路径遍历、任意 branch/repo 参数被拒绝。
- [ ] 不可信 source URL 不执行/不自动服务端抓取；Markdown 不开启 raw HTML。
- [ ] 伪装 SVG/HTML、错误 MIME、超大小文件不能进入 canonical；只靠扩展名不算验证。
- [ ] presigned URL 只允许指定暂存键，过期生效；最终键不可用旧签名覆盖。
- [ ] PAT/R2/HMAC/Access配置不进入前端 bundle、日志、Git、截图或错误响应。
- [ ] PR workflow 无 Secrets，无 pull_request_target 执行不可信代码；正式发布只针对审查过的 main。
- [ ] 上传发布时明确告知公开性和 Git 历史；参考图必须主动选择。

## D. 视觉和无障碍

- [ ] 1440/1280/768/390/360px 无水平溢出，图片比例正确，九宫格和长图不隐性裁切。
- [ ] 默认首屏先看见作品，没有广告/指标卡/复杂左侧栏。
- [ ] 所有按钮可键盘操作，focus 可见；模态框捕获/恢复焦点，Esc 关闭。
- [ ] 卡片复制与打开详情分开，触摸区域足够；手机不是只能 hover 才出现关键按钮。
- [ ] 切换详情媒体不累积视频播放；图片替代文字和按钮标签完整。
- [ ] 图片加载有 width/height 占位，布局稳定；对比度与 reduced-motion 通过检查。

## E. 性能与费用路径

- [ ] 公开 HTML/JS/CSS 走 Static Assets；不全站 `run_worker_first: true`。
- [ ] 原始媒体不在 Git、不在 dist、不在 GitHub Actions artifacts/cache；模板例外明确。
- [ ] 列表读取缩略图，详情默认预览；不会进入页面就下载所有原图/视频。
- [ ] 生产媒体使用 R2 自定义域名，正确 MIME/缓存，实测 Range 206。
- [ ] staging/备份/缩略图/旧对象计入存储估算，免费额度是账号级共享。
- [ ] 观察真实 Worker CPU，再判断是否需要 $5 Paid；没有无证据“永远零费用”承诺。
- [ ] 公开页不接统计/广告/模型 API 等隐性依赖。

## F. 建议测试样本

1 张 1024px PNG、1 张约 20MiB 大 PNG、1 张手机 JPEG、1 张超长九宫格、8 张同组图、1 段 H.264 MP4、1 段 WebM、1 个不兼容 MOV、1 份伪装图片 HTML、一个包含超长中英文及 JSON 的 Prompt、一个未知模型记录、两个并发编辑页面。

前端目标预算（工程验收目标，不是平台保证）：桌面列表布局 CLS <0.1；普通中等网络首页 LCP 约 <=2.5s；默认公开页不加载编辑器 JS。以可复现的设备、网络、版本记录测试，不只贴一个分数。


## 媒体发布并发补充

- [ ] 同一 receipt 两个并发 finalize，目标 key 仅创建一次。
- [ ] staging 在 HEAD 后被重传覆盖，带源 ETag 的后续读取失败并阻止发布。
- [ ] 已存在 final 对象的 requestId/尺寸/类型不符，拒绝覆盖和引用。
- [ ] 250 MiB 视频流式复制不读取整文件进内存；目标条件失败后正确取消/释放源流。
